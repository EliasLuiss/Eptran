# EPTRAN

Projeto educativo sobre trânsito, com duas versões do site:

- `eptran/`: primeira versão, em HTML, CSS e PHP.
- `eptran_nextjs/`: versão em Next.js (TypeScript) com jogos, quizzes, área de conteúdo e painel administrativo.

## Como rodar a versão Next.js

```bash
cd eptran_nextjs
npm install
npm run dev
```
